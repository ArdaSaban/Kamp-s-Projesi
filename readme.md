# Kampüs Kulübü - Spor Bilimleri Fakültesi Web Sitesi

Bu proje, **BPR201 - İnternet Tabanlı Programlama** dersi kapsamında geliştirilmiş eğitim amaçlı statik bir web sitesidir.

## Proje Hakkında
Site; Ana Sayfa, Etkinlikler ve Hakkımızda olmak üzere üç ana sayfadan oluşur. Kullanıcılar etkinlikler sayfasında anlık (live) arama motoru ile etkinlik filtrelemesi yapabilir.

## Kullanılan Teknolojiler
- **HTML5** (Semantik etiketler, erişilebilirlik)
- **CSS3** (Grid sistemi, Flexbox, Responsive tasarım)
- **JavaScript (ES6+)** (DOM manipülasyonu, canlı arama filtresi)

## Kurulum ve Çalıştırma
1. Proje dosyalarını bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasını herhangi bir web tarayıcısında (Chrome, Edge, Firefox vb.) açın.
